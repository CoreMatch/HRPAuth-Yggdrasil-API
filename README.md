Armorial Yggdrasil API brings a Yggdrasil and authlib-injector interface to Minecraft clients, backed by a running Armorial identity center.

It serves authentication, token refresh, server joins, profiles, and textures while linking Microsoft and Mojang accounts.

## Why Armorial Yggdrasil API

- **One account backbone.** Use Armorial credentials across compatible game clients.
- **Standard client flow.** Support auth, refresh, join, and profile operations through Yggdrasil.
- **Connect existing identities.** Bind Microsoft and Mojang accounts to Armorial ecosystem profiles.
- **Carry profiles and textures.** Serve player profile data and skin and cape textures.
- **Extend the portal.** Include an embedded WebUI SDK for Armorial-hosted pages.

## Compatibility

Yggdrasil and authlib-injector support does not imply universal compatibility with every Minecraft client or launcher.
